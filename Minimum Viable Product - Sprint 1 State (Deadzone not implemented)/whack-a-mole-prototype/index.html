Whack-a-Mole Grid Prototype

This demo visualises the game loop behind the project: a player acts as a cursor, moves across a 3x3 grid, and must stand on the mole tile before the timer expires.

Level 1
Score 0
Timer 4.0s
Cursor A1
Mole B2
Press Start, then use the arrow keys or WASD to move the cursor.

Interface Logic

Current target ruleStand on mole at timeout
Grid size3 x 3
Round speed4.0s
Arrow Keys or W A S D move the cursor.
If the cursor is on the mole when the timer expires, you score a hit.
Every 3 hits, the round gets faster to simulate increasing difficulty.
This keeps the tester focused on the interface and game loop rather than the physical sensor stack.
In the hardware version, the physical player would replace the cursor position data. This visualiser keeps the logic simple so you can validate the concept, the timing, and the level progression.
